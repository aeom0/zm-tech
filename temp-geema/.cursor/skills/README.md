# Skills del proyecto (Cursor + Claude Code)

```
.claude/skills → ../.cursor/skills
```

| Ruta | Rol |
|------|-----|
| `SKILLS.md` | Guía de conocimiento profundo GeemaStudio (ambos agentes) |
| `geemastudio.md` | Alias → `SKILLS.md` (compatibilidad) |

| `ui-styling/` | Tailwind / shadcn / theming |
| `design-system/` | Design tokens y specs |
| `brand/` | Identidad, voz, sync brand → tokens |
| `meta-ads-manager/` | Meta Ads / CTWA vía MCP |

## No copiados desde ZM (opcionales)

Si los necesitas: `design/`, `slides/`, `banner-design/`, `social-media-organic/` en el repo ZM.

Para agregar otra skill: descomprimir el `.skill` (zip) en una carpeta kebab-case con `SKILL.md` dentro de este directorio. Queda disponible en Cursor y Claude al instante.
